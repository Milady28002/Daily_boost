# Daily Boost - Dossier Projet

Mini application Symfony permettant de gérer une bibliothèque de citations inspirantes.

## Fonctionnalités

- Ajouter une citation
- Modifier une citation
- Supprimer une citation
- Marquer une citation comme favorite
- Afficher une citation aléatoire
- Citation du jour
- Tableau de bord des statistiques

## Stack technique

- Symfony 7
- Twig
- Doctrine ORM
- PostgreSQL
- HTML / CSS

## Objectif

Projet réalisé dans le cadre de ma formation **Graduate Développeur Web Full Stack** chez Studi.
